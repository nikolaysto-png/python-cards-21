# Blackjack 🂡

Single-player animated blackjack vs the dealer. No build step, no dependencies, no saved progress (fresh 500 chips every visit).

**Play:** open `index.html` in any browser, or GitHub Pages.

## Controls
- **1 / 2 / 3 / 4** — bet 25 / 100 / 250 / 500 chips (or click chips)
- **0** — all-in · **Backspace** — clear bet
- **Enter** — DEAL
- **H / S / D / P** — Hit / Stand / Double / Split
- ✦ cycles card skins (Standard, Holographic, Gold, Neon, Mystic)
